# Rosid Syndicate Company

Official website and corporate portal for Rosid Group of Companies.

## Tech Stack
- **Framework**: React, Vite, TypeScript
- **Styling**: Tailwind CSS, Lucide Icons
- **Deployment**: Vercel

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
